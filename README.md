# BarniesScheduler
A python executable that allows stage managers to automate scheduling rehearsals by inputting actors schedules and other priorities. 

To run, download a python interpreter (open source, free) and save all the code to one folder. Then, run the script called ScheduleGUI.py

After inputting actor information and schedules, it will be saved to a json file which can be edited when necessary and re-uploaded each week to create a new schedule.
